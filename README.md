# Validacion de compilacion con GitHub Actions

Grupo: IDSM41

Practica de validacion de configuracion de Docker Build y Docker Bake.

El flujo comprueba la configuracion, construye las imagenes y ejecuta
una aplicacion Python que muestra y verifica operaciones aritmeticas.

Referencia:
https://docs.docker.com/build/ci/github-actions/checks/
